# דפי חזרה – ח׳3

## הפעלת קליטת ההגשות (Google Sheets, כ-5 דקות)
1. צרו Google Sheet חדש ← **Extensions ← Apps Script**.
2. הדביקו את התוכן של `apps-script.gs` ושמרו.
3. **Deploy ← New deployment ← Web app**: Execute as: *Me*, Who has access: *Anyone* ← Deploy ואשרו הרשאות.
4. העתיקו את כתובת ה-Web app (נגמרת ב-`/exec`) והדביקו ב-`config.js` בין המירכאות.

## מעקב הגשות
בגיליון: File ← Download ← CSV (לשונית submission), ואז פתחו את `admin.html` באתר והעלו את הקובץ.
